# Terminal-policy comparison v1

This diagnostic compares explicit stopping definitions and allocation methods
over one authenticated candidate dossier. It uses the disjoint receipt
components for candidate-linked authorized and unresolved committees. Memo
subtotals remain visible outside the numeric scope.

Every scenario partitions the same included row population into exclusive
`direct`, `explicitly_earmarked`, `proportional`, and `unresolved` buckets.
Rows and known signed minor units must conserve exactly. Unknown-amount rows
conserve by count and remain unresolved.

No scenario is selected. The result does not establish a complete candidate
funding denominator, a resolved person or organization, cash availability, or
terminal eligibility. Blocked methods emit no modeled dollars.

`result.schema.json` is the normative JSON contract.
