# Independent-expenditure candidate interpretations v1

This calculation consumes one immutable candidate-resolution v1 publication and
preserves each source decision as one interpretation. It separates the
filer-reported endpoint from a unique exact-context alternative and supplies a
safe default endpoint only when the reported ID and exact context agree.

An alternative endpoint is evidence, not another expenditure. Each source amount
appears once and remains classified as confirmed, inferred, conflicting,
unverified, ambiguous, or unresolved. The publication does not alter the retained
candidate-resolution calculation or any graph.
