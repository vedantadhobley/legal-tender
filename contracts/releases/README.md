# Release contracts

Release contracts define how individually versioned publisher artifacts become
one reproducible Legal Tender release. They do not imply that a publisher
updated every artifact atomically.

- [`fec/v1/`](./fec/v1/) — initial 21-member FEC inventory, metadata-only
  discovery, deterministic release planning, and accepted release manifests.
- [FEC v2](./fec/v2/) — historical extension adding processed Schedule E.
- [FEC v3](./fec/v3/) — active/default extension adding archive-direct Schedule B.
- [FEC v4](./fec/v4/) — opt-in whole committee-summary CSVs; real activation pending.
